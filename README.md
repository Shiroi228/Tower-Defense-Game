# Tower Defense Game (Qt/C++)

## Описание проекта

Это классическая игра в жанре **Tower Defense** (Оборона башни), разработанная с использованием фреймворка **Qt** и языка **C++**. 

В игре вы защищаете свою базу от волн атакующих врагов, стратегически размещая башни для защиты ключевых точек.

## Технологии

- **Язык:** C++
- **Фреймворк:** Qt (сборка через CMake)
- **Геймплей:** Реализован классический Tower Defense с механиками:
  - Размещение башен для защиты базы
  - Атаки вражеских волн
  - Стрельба башнями по цели
  - Управление ресурсами

## Установка и запуск

1. Убедитесь, что у вас установлены **Qt 6.x**, **CMake** и **MSVC** (или MinGW для Windows).
2. Выполните следующие команды в терминале:
   
   ```bash
   mkdir build && cd build
   cmake .. -DCMAKE_PREFIX_PATH=/путь/к/qt/
   cmake --build .
   ```

3. После сборки запустите игру через сгенерированный исполняемый файл, например: `Release/TowerDefense.exe`.

## Зависимости

Для работы проекта требуются:
- Qt 6.x SDK
- CMake 3.16+
